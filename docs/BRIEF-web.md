# Brief — เว็บเจ้าหน้าที่ (citydata-web)

> อ่าน [BRIEF.md](BRIEF.md) ก่อนถ้ายังไม่ได้อ่าน

**ไฟล์ที่คุณดูแล: `web/index.html` ไฟล์เดียว** ไม่ต้องแตะไฟล์อื่นเลย

## เป้าหมาย

ทำหน้ารายละเอียดเรื่องแจ้งของ citydata ให้เหมือนของจริง เพื่อให้เจ้าหน้าที่ที่มารีวิว
รู้สึกเหมือนกำลังใช้ระบบจริง แล้วเห็นว่าเมื่อเจอเรื่อง sensitive หน้าตาจะเปลี่ยนไปยังไง

ตอนนี้ผมทำโครงหยาบๆ ไว้ให้แล้ว — topbar, รายการแจ้งด้านซ้าย, การ์ดรายละเอียด
และส่วน sensitive ที่กดใช้ได้จริง **สิ่งที่ขาดคือความเหมือน** เพราะผมไม่มีโค้ด citydata
ตอนที่ทำ เลยเดาหน้าตาเอาจากที่เห็นผ่านๆ

## สิ่งที่ต้องทำ

### 1. ทำของเดิมให้เหมือนของจริง

เปิด `web/index.html` เทียบกับหน้า detail จริงใน citydata-web
(`src/components/PostManagementNew.js`) แล้วแก้ให้ตรง

ที่น่าจะไม่ตรงและควรแก้ก่อน:

- **topbar** — เมนู สี โลโก้ ความสูง ตอนนี้ผมใส่ไปมั่วๆ
- **การ์ดรายละเอียด** — layout ของ meta (สถานะ ประเภท หน่วยงาน แจ้งเมื่อ ที่อยู่)
  ตอนนี้เป็น `<dl>` สองคอลัมน์ ของจริงอาจไม่ใช่แบบนี้
- **สี/ฟอนต์/ระยะห่าง** — ผมใช้ฟอนต์ Anuphan ตามที่เห็นใน `index.css` ของ citydata
  ถ้าของจริงต่างจากนี้แก้ได้เลย
- **การ์ดสถานะ** (`.status-pill`) — สีตามสถานะจริงเป็นยังไง

ลอก class name จากของจริงมาใช้ได้เลยถ้าอยากให้ตรงที่สุด แต่ต้องเขียน CSS เองใน `<style>`
เพราะที่นี่ไม่มี Tailwind/Bootstrap/antd

> ถ้าจะให้เร็ว: copy CSS ที่เกี่ยวข้องจาก citydata มาแปะใน `<style>` ของไฟล์นี้เลยก็ได้
> ขอแค่อย่าลิงก์ไปหา CDN ข้างนอก

### 2. เติมช่องที่เว้นไว้

ในไฟล์มีกรอบเส้นประ 3 ช่อง (`class="slot"`) เขียนบอกไว้ว่าตรงนั้นควรมีอะไร
ให้แทนที่ด้วย UI จริง (เป็น HTML นิ่งๆ ก็พอ ไม่ต้องกดทำงานได้)

| ช่อง | ต้องทำ |
| --- | --- |
| แถบเครื่องมือจัดการเรื่อง | ปุ่มปรับสถานะ, ส่งต่อหน่วยงาน, มอบหมายเจ้าหน้าที่ — หน้าตาให้เหมือนของจริง |
| Timeline การดำเนินงาน | **สำคัญ** อ่านข้อ 3 |
| แชทกับผู้แจ้ง | ยังไม่อยู่ในเฟสนี้ ลบช่องนี้ทิ้งได้เลย |

### 3. จุดที่สำคัญที่สุด — Timeline ตอนเป็นเรื่อง sensitive

นี่คือสิ่งที่เราอยากได้ feedback มากที่สุด

เมื่อเรื่องเป็น sensitive **timeline จะไม่แสดงเป็นข้อความอีกต่อไป** แต่จะถูกแทนด้วย
ภาพที่ render มาพร้อมลายน้ำ (ซึ่งคือส่วนที่ `mountSensitiveFlow` แสดงอยู่แล้ว)

สิ่งที่อยากให้ทำคือแสดงให้เห็น **ทั้งสองแบบเทียบกัน** เพื่อให้คนรีวิวเข้าใจว่าต่างกันยังไง:

- ทำ timeline แบบปกติ (มีข้อความ) ไว้ในเรื่องอื่นที่ไม่ sensitive
- ส่วนเรื่องที่ sensitive ให้เห็นว่ากลายเป็นภาพแทน

วิธีที่ง่ายที่สุดคือทำให้รายการแจ้งด้านซ้าย **กดสลับเรื่องได้จริง** — เรื่องที่มีป้าย
"ข้อมูลอ่อนไหว" แสดงแบบ sensitive ส่วนอีกสองเรื่องแสดง timeline ปกติ
ตอนนี้กดไม่ได้ เป็นแค่รูป

### 4. อย่าแตะส่วน sensitive

```html
<div class="sv-root" id="sensitive-slot"></div>
```

กับ script ท้ายไฟล์ที่เรียก `mountSensitiveFlow()` — สองอย่างนี้ทำงานได้แล้ว
ย้ายตำแหน่งได้ แต่อย่าลบ อย่าแก้ข้างใน

ถ้าอยากปรับหน้าตาของส่วน sensitive ให้เข้ากับ citydata มากขึ้น
เขียน CSS override ทับใน `<style>` ของไฟล์ตัวเองได้ ตัวแปรที่ปรับได้อยู่ใน
`shared/sensitive-flow.css` (`--sv-accent`, `--sv-radius` ฯลฯ)

## สิ่งที่อยากได้ feedback จากคุณด้วย

ระหว่างทำ ถ้าเจอว่าอะไรใช้งานไม่สมเหตุสมผล บอกได้เลย โดยเฉพาะ

- เจ้าหน้าที่ต้องใส่ PIN ทุกครั้งที่เปิดเรื่อง sensitive — ในงานจริงจะรำคาญไหม
- การอ่านรายละเอียดจากภาพแทนข้อความ ทำงานจริงไหวไหม (copy ข้อความไม่ได้ ค้นหาไม่ได้)
- ถ้าเจ้าหน้าที่ต้องดูหลายเรื่องติดกัน flow ควรเป็นยังไง
